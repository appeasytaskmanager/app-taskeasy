## 📞 Referências Rápidas

### Iniciar Projeto
```bash
npm install && npm run dev
```

### Acessar Dashboard
```
http://localhost:3000/dashboard
```

### Build
```bash
npm run build
```

### Lint
```bash
npm run lint
```

### DB (Drizzle)
```bash
npm run db:push
npm run db:generate
npm run db:migrate
npm run db:studio
```
